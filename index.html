How a CNN reads an image

A convolutional network never looks at a picture the way you do. It slides small filters over a grid of numbers and keeps track of where something interesting shows up.

This page walks through each piece in order. Everything that moves is a real calculation, so pause it, change a setting, and check the arithmetic yourself.

Convolution and padding

A filter is a small grid of weights. Place it on the image, multiply each weight by the pixel under it, add everything up, and you get one number. Slide it one step and repeat. The numbers you collect make a feature map.

The same nine weights are used at every position, which is why a CNN finds an edge wherever it appears.

Padding puts a ring of zeros around the image so border pixels count as much as the middle ones and the output doesn’t shrink. Stride is how far the filter jumps each move.

Pooling

Feature maps are big and a little redundant. Pooling shrinks them: look at a 2×2 window, keep one value, move on. Max pooling keeps the strongest response, average pooling keeps the mean.

There is nothing to learn here, no weights at all. The payoff is a smaller layer and some tolerance for the object sitting a pixel or two off.

ReLU and sigmoid

If every layer only added and multiplied, the whole network would collapse into a single linear formula. Activation functions put a bend in the middle so the network can learn curves.

The pink dashed line is the gradient, the number backpropagation multiplies by. Where it’s near zero, learning stalls.

One neuron, one update

A neuron takes inputs, multiplies each by a weight, adds a bias, and applies an activation: a = σ(w₁x₁ + w₂x₂ + b).

Here x₁ is 0.8, x₂ is 0.3, and the right answer is 1. Drag the weights and watch the loss and the gradient respond.

The gradient comes from the chain rule: ∂loss/∂w₁ = 2(a − 1) · a(1 − a) · x₁. If it’s negative, raising w₁ lowers the loss. Gradient descent then sets w₁ to w₁ − η · gradient.

Dense layers, forward and backward

After the last pooling step the feature maps are flattened into one long list. In a dense layer, also called fully connected, every neuron receives every value from the layer before.

Forward propagation runs left to right and ends in a prediction. The loss says how wrong it was.

Backward propagation runs right to left. Using the chain rule, each weight learns how much it contributed to the error, then moves a small step to reduce it.
